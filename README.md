# A Practitioner's Guide to Agentic AI Tools

**Gonzalo Ballestero**  
Pennsylvania State University — gballestero@psu.edu

---

These are the slides for a talk on how economists can use agentic AI tools in their research workflow, with a focus on Claude Code.

## Contents

The talk covers four topics:

- **Why AI Agents?** — How agents differ from chatbots, and why that matters for research
- **How to Deploy AI Agents?** — CLI vs. IDE, and how to set up Claude Code with VS Code
- **How to Use Claude Code?** — Project folder structure, the `CLAUDE.md` file, and skills
- **Best Practices and Resources** — Prompting tips and a curated list of learning resources
